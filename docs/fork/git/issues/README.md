## 依存関係

```
GIT 01（右サイドバーに Git モード）
   ↓ 器が無いと中身を置けない
GIT 02（変更ファイル一覧）
   ↓ 一覧が無いとクリック対象が無い
GIT 03（一覧から差分をカラムに開く）
```

**直列**。並行して進められる箇所は無い。
