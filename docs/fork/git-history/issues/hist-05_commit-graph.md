## 📐 先に決めること

**描画方式が未確定** `[docs/fork/git-history/01_要求定義.md §5.4]`。

| 候補 | 利点 | 懸念 |
|---|---|---|
| 固定パスの `file://` | URL が変わらないので既存の完全一致判定でタブが1枚に保たれる | `file://` がブラウザパネルで開けるか未検証。差分ビューアは `bypassRemoteProxy: true` を要した |
| 独自スキーム | 差分ビューアと同じ扱いにできる | 登録経路が upstream 所有で、触ると追従コストが増える |

着手直前に、小さい HTML を実際に開いて決める。**決めた根拠を
`01_要求定義.md §5.4` に書き戻す。**
