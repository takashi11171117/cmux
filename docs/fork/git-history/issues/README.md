# Git 履歴・グラフ タスク一覧

仕様は `docs/fork/git-history/` の 01〜03。

## 依存関係

```
HIST 01（器）─┐
              ├─→ HIST 03（一覧）──→ HIST 04（差分を開く）
HIST 02（データ）┘         │
                           └─→ HIST 05（グラフ・段階B）
```

HIST 01 と 02 は**並行して進められる**。

## 一覧

| 番号 | 内容 | 段階 | 依存 |
|---|---|---|---|
| HIST 01 | 右サイドバーに History モードを追加 | A | なし |
| HIST 02 | 履歴データ層（コマンド・パース・サービス） | A | なし |
| HIST 03 | コミット一覧の表示とページング | A | 01, 02 |
| HIST 04 | 行からコミットの差分を開く | A | 03 |
| HIST 05 | コミットグラフ | B | 03 |

**段階A（HIST 01〜04）で日常の用は足りる。** そこで導線が確定してから段階B に入る。

## この機能で先に潰した罠

実測で確定済み。実装時に踏まないこと。

- **`git show` はマージコミットの差分を既定で抑制する**（0行になる）。
  `--first-parent` を常に付ける。`--root` は不要
- **`RightSidebarMode` の `from(cliArgument:)` と `paneModes` は
  `switch` の網羅性で検出されない**。足し忘れてもコンパイルは通る
- **`CMUX_WORKSPACE_ID` 等を消さないとターミナルが分割される**。
  CLI 単体テストでは再現しない
- **`Localizable.xcstrings` を JSON として再直列化しない**。差分が万行になる
