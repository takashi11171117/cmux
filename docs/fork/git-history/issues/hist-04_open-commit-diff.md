## 🎯 目的

履歴の行をクリックすると、そのコミットが変えた内容がコードレビューカラムに開く。
導線は Git タブの「行クリック → カラムに差分」と揃える。

**依存: HIST 03。**

## ✅ やること

- [ ] `AppDelegate` にコミット差分をカラムへ開く経路を足す
- [ ] `GitCommitPatchCommand`（HIST 02）でパッチを作り、標準入力に流す
- [ ] 行の `onOpen` から呼ぶ
- [ ] 手動テスト仕様書に項目追加

## ⚠️ 落とし穴

**`CMUX_WORKSPACE_ID` / `CMUX_SURFACE_ID` / `CMUX_SOCKET` を消す。**
残すと CLI が分割元のペインを探しに行き、**カラムではなくターミナルが分割される**。
先行機能でこれを踏んでいる。**CLI 単体のテストでは再現せず、GUI から呼んだときだけ
壊れる**（CLI ヘルパーがこれらを scrub するため）。

**既存の差分ビューアを改変しない。** パッチを標準入力に流すだけ。`cmux diff` の
経路は upstream 所有で、触ると追従コストになる。

**差分タブは1枚に保つ。** `showBrowser` がスキームで照合するので、既存の経路に
乗る限り自動的に満たされる。

## 🧪 完了条件

- 行をクリックすると差分がカラムに開き、赤緑の行が描画される
- **マージコミットでも差分が出る**（HIST 02 の `--first-parent`）
- ルートコミットでも差分が出る
- 何度開いても差分タブは1枚のまま
- ターミナルが分割されない
